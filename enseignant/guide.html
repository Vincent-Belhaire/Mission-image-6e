GUIDE PROFESSEUR · TICE 6e · SÉANCE 08

Mission image

55 minutes · une séance tous les 15 jours · LibreOffice Writer + Firefox

Ce que les élèves vont réellement faire

Dans le site : 5 défis autocorrectifs sur l’insertion, le transfert depuis une galerie, les proportions, le placement et le contrôle de la fiche. Dans Writer : illustrer un document fourni avec deux images, le sauvegarder dans leur espace personnel, le rouvrir et contrôler son aperçu.

Prérequis : ouvrir Writer, enregistrer un fichier, créer un paragraphe, sélectionner un objet et reconnaître un chemin. Réinvestissement des séances 3, 6 et 7.

La charte reprend les valeurs CSS du Bureau Mystère : fond crème, en-tête violet sombre, jaune ambré, turquoise, cartes bordées et ombres franches. Pas de commande de zoom ni d’échelle globale imposée. Le zoom normal du navigateur reste disponible pour l’accessibilité.

Préparer la salle

  1. Extraire le ZIP. Ouvrir index.html dans Firefox, ou publier le contenu du dossier sur GitHub Pages.
  2. Vérifier que les élèves ont accès à Writer et à leur dossier de travail. Chemin proposé : P:\Documents\TICE\Documents. Le chemin est indicatif et peut être adapté.
  3. Tester sur un poste le glissement de l’image de galerie.html vers Writer. Il dépend du système et des versions. Le fichier PNG et l’insertion locale sont fournis comme solution de secours.
  4. Préparer éventuellement le dossier de classe avec ressources/fiche_depart.odt et les deux PNG. Chaque élève travaille sur sa copie, jamais sur le fichier source partagé.
  5. Pour l’impression, choisir A4 portrait, échelle 100 %, sans en-têtes/pieds de page du navigateur. Aucun fond de couleur n’est nécessaire pour lire le bilan.

Postes partagés : la sauvegarde dans le navigateur est facultative. Sans elle, fermer ou recharger la page fait perdre la progression. Avec elle, demander aux élèves d’imprimer/exporter leur bilan, puis d’utiliser « Nouvel élève · tout effacer ». Aucun serveur de résultats et aucun suivi de navigation ne sont intégrés.

Barème et interprétation du bilan

1000 points, répartis en 5 domaines de 200 points. Les points ne sont attribués qu’une fois par critère réussi, y compris après correction. Il n’y a pas de retrait automatique lié aux erreurs ou aux aides.

Repères : Acquis = tous les critères du domaine ont été réussis ; En cours = une partie ; À revoir = essayé sans réussite ; Non réalisé = aucun essai. Les aides et reprises restent indiquées. « Acquis » ne signifie donc pas nécessairement « autonome au premier essai ».

Le temps affiché compte uniquement les secondes où cet onglet a le focus, hors accueil et bilan. Ce n’est ni le temps total de séance, ni un critère d’évaluation. Le travail hors du navigateur est exclu.

Important : le site ne lit pas le .odt et ne vérifie pas la mission réalisée dans Writer. Les 7 cases sont un autocontrôle distinct du score. La zone de validation professeur est à renseigner après observation. L’export JSON ne contient pas le document Writer.

Corrections des défis

  1. Insertion : Insertion → Image → robot_pixel.png → Ouvrir. Choisir l’incorporation sans « Lier ».
  2. Firefox : déposer l’image du jardin dans la fiche. En cas d’échec réel, enregistrer l’image puis Insertion > Image.
  3. Taille : activer le ratio avant modification, largeur 8 cm, hauteur 5 cm. Utiliser une meilleure source ou une taille plus petite si la qualité est insuffisante. Si l’élève verrouille après avoir déformé, rétablir les dimensions d’origine.
  4. Placement : « Comme caractère », « Centré », puis emplacement ①.
  5. Qualité : image B ; revoir position/ancrage/adaptation ; image autorisée fournie ; enregistrer, rouvrir et contrôler l’aperçu.

Points de vigilance techniques

Les exercices sont des interfaces simplifiées, pas une reproduction exhaustive de Writer. Les noms et emplacements d’options varient selon les versions ; les aides le signalent. La méthode numérique « Propriétés → Position et taille / Type → Conserver le ratio » est privilégiée plutôt qu’un comportement supposé universel des poignées.

L’ancrage « Comme caractère » est enseigné pour stabiliser cette fiche. Il n’empêche pas de découvrir ensuite l’ancrage au paragraphe et l’adaptation du texte. Pour déplacer une image en ligne, couper/coller dans un paragraphe vide est une méthode simple.

Le glissement entre applications n’est pas une fonction du mini-site : c’est Firefox et Writer qui le réalisent. Selon l’installation et la source de l’image, un lien peut être créé ou le geste peut échouer. Le support propose alors l’insertion locale sans lien et demande de noter la méthode employée.

Autonomie technique : pas de CDN, pas de police à télécharger, pas de compte, pas de statistiques externes, pas d’appels à une API. Les liens de documentation ne s’ouvrent que sur demande.
